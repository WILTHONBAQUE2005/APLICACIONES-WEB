Evaluacion Parcial 2 - Sistema de Gestion de Hospitales

Proyecto con .NET 8 + Angular para gestionar pacientes, doctores y citas medicas.

Requisitos

XAMPP (MySQL/MariaDB)

.NET 8 SDK

Node.js

Ejecutar

Importar database/hospital_management_db.sql en phpMyAdmin.

En backend/HospitalManagement.Api: ejecutar dotnet restore y luego dotnet run

En frontend/hospital-management-ui: ejecutar npm install y luego npm start

Abrir http://localhost:4200

Nota

La API esta configurada en http://localhost:5262 y la conexion a MariaDB usa root sin contrasena en XAMPP.
